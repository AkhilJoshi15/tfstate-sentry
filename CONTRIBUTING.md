# Contributing

Contributions are welcome when they can be tested with public or synthetic data.

## Rules

- Never submit real state, plan files, credentials, customer data, or employer-confidential code.
- Add a synthetic fixture and regression test for every detector.
- Findings must never contain the detected value.
- Keep the scanner offline by default.
- Run `make fmt vet test` before opening a pull request.

By contributing, you certify that you have the right to submit the work under the repository license.

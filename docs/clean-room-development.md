# Clean-room development record

This project is developed using personal equipment, personal accounts, public documentation, and synthetic Terraform fixtures.

The repository must not contain:

- employer source code or Terraform modules
- employer state or plan files, including sanitized copies
- internal architecture, incident details, credentials, or screenshots
- customer or production data
- code copied from proprietary systems

Synthetic fixtures use invalid example values and reserved domains such as `example.invalid`.
